PowerShell edition 0.1.1 - documentation-only revision. The mod code is unchanged from PowerShell 0.1.0.

Download **The-Wolf-Among-Us-Remastered-Ultrawide-Fix-PowerShell-0.1.1.7z** from Assets below, extract the entire folder, and read README.txt. Use Windows PowerShell 5.1 (powershell.exe), rather than PowerShell 7. Close the game, run Ultrawide Setup.ps1, select the game folder and resolution, then select that mode in the game's graphics settings.

Includes presets, custom dimensions, supported-executable checks, backups and undo. No EXE or DLL is bundled: Windows compiles the included readable C# helper source locally. This is an alternative setup for the same fix; the graphical edition remains available. See the README for protected-folder permissions and script-policy troubleshooting.

The underlying 3440 x 1440 rendering correction is player-confirmed. Other resolutions are offered for testing, and 5120 x 1440 is experimental. Menus retain their centred layout and wider framing can expose scenery/transition edges. PowerShell loading and private-copy install/update/undo tests passed; this edition has not received a fresh full gameplay test.

The matching .sha256 asset verifies this unchanged package. Readable source and the full player README are under powershell/ in the repository.
