Initial ultrawide test release with a Windows setup tool, common presets, custom dimensions, exact executable checks and undo.

3440×1440 is player-confirmed for the underlying rendering fix. Other resolutions are offered for testing; 5120×1440 is experimental. Original menus remain centred, and wider scene framing can reveal offscreen edges. The generalized setup/menu has not received a full desktop/gameplay test.

Download the `.7z` asset and extract it, then read `README.txt`. The matching `.sha256` file records the package checksum. Source and build instructions are included in this repository.
